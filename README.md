# Hotel Booking Confirmation Page

## Overview

This project implements the Frontend Mentor Hotel Booking Confirmation Page challenge using HTML, CSS, and Bootstrap. It displays a booking receipt, a welcome message, arrival instructions, Wi-Fi details, and breakfast information.

Challenge link: https://www.frontendmentor.io/challenges/hotel-booking-confirmation-page 


## Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3
- Google Fonts

## Approach and Custom Styling

I used Bootstrap containers, rows, and columns to build the responsive layout. Bootstrap cards, buttons, spacing utilities, and flex utilities helped organize the content.

I added custom CSS for the design’s colors, fonts, shadows, and overlapping booking cards. Bootstrap order classes display the welcome card before the receipt on mobile. I also used Bootstrap’s offcanvas component for the mobile navigation menu.

The goal was to match the supplied design rather than introduce a different visual style. The Copy, Print receipt, and Add to calendar buttons are visual elements only.

## Challenges and Solutions

- Missing closing tags caused layout problems. I checked the HTML structure and corrected the tags.
- Misspelled Bootstrap classes prevented styles from working. I compared the class names and corrected them.
- Image paths needed to match the assets folder. I checked the filenames and corrected the paths.
- The mobile layout required a different card order. I used responsive Bootstrap order classes.
- I checked the page in browser developer tools at a mobile width of 375px.

## Reflection

One challenge I faced was understanding how Bootstrap classes work together to create a responsive layout. I also had problems with missing closing tags, misspelled class names, and incorrect image paths. These small mistakes sometimes changed the layout or prevented icons from appearing.

To solve these problems, I worked on one section at a time, checked the HTML structure, and compared the page with the supplied design. I used Bootstrap’s grid system and utility classes to organize the cards, buttons, and navigation. Browser developer tools helped me check the mobile layout and change the order of the booking cards.

This project helped me understand containers, rows, columns, flex utilities, and responsive classes. If I had more time, I would improve the spacing and typography to match the design more closely, test more screen sizes, and add functionality to the Copy, Print receipt, and Add to calendar buttons.
